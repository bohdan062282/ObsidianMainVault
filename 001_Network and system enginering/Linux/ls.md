### Description
list directories

---
### Basic syntax
```bash
ls [опции] [путь]
```

**Полезные опции:**
- `-l` — длинный формат (права, владелец, размер, дата).
- `-a` — показать скрытые файлы (начинаются с `.`).
- `-h` — размеры в читаемом виде (KB, MB).
- `-t` — сортировать по времени.
