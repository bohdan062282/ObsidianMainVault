## Description
Фундаментальные файлы, в которых хранится базовая информация по поводу юзеров и их логинов.

---
## User files

### Sudoers file
---
`sudoers` — конфигурационный файл, который определяет **кто и какие команды может выполнять через `sudo`**, и при каких условиях.
```bash
/etc/sudoers
```

*Для редактирования только `visudo`.*
- `visudo` проверит синтаксис перед сохранением.
- Если ты ошибёшься, `sudo` может перестать работать, и придётся лезть в систему через root-доступ.

- #### Синтаксис записей:
	```bash
	user    host    = (runas)    commands
	```
	- **user** — имя пользователя или группа (`%groupname`).
	- **host** — с каких хостов можно выполнять (`ALL` — с любых).
	- **runas** — от имени какого пользователя можно выполнять (`ALL` — любого, обычно root).
	- **commands** — список команд (с полными путями, например `/usr/bin/apt`).
	
	##### Пример 1 — дать пользователю `alex` права на всё
	```bash
	alex    ALL=(ALL:ALL) ALL
	```
	
	##### Пример 2 — дать группе `admins` права на всё
	```bash
	%admins ALL=(ALL:ALL) ALL
	```
	
	##### Пример 3 — дать `alex` права только на перезапуск Apache без пароля
	```bash
	alex ALL=(ALL) NOPASSWD: /bin/systemctl restart apache2
	```
	
	В конце `/etc/sudoers` часто есть строка:
	`#includedir /etc/sudoers.d`
	- Это значит, что все файлы в `/etc/sudoers.d/` тоже загружаются.
	- Удобно добавлять конфиги для отдельных пользователей без правки основного `sudoers`.
	
	После изменений можно проверить:
	```bash
	sudo -l   # показывает, что именно разрешено текущему пользователю
	```


### Passwd file
---
Хранит **информацию о всех пользователях системы**.  
Название историческое: когда-то там реально хранились пароли, но сейчас пароли вынесены в `/etc/shadow`.

Каждая строка описывает одного пользователя в виде 7 полей, разделённых двоеточиями:
`имя_пользователя : пароль : UID : GID : комментарий : домашний_каталог : shell`

Пример строки:
`alex:x:1000:1000:Alex Ivanov,,,:/home/alex:/bin/bash`

| Поле                  | Пример           | Описание                                                                                                                                                    |     |
| --------------------- | ---------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------- | --- |
| **1. username**       | `alex`           | Логин пользователя                                                                                                                                          |     |
| **2. password**       | `x`              | Раньше тут был хэш пароля, сейчас `x` — значит, пароль хранится в `/etc/shadow`; если `*` - значит у юзера нет доступа для входа; если пустой - нет пароля. |     |
| **3. UID**            | `1000`           | **User ID** — уникальный идентификатор пользователя                                                                                                         |     |
| **4. GID**            | `1000`           | **Group ID** — ID основной группы пользователя (см. `/etc/group`)                                                                                           |     |
| **5. GECOS**          | `Alex Ivanov,,,` | Комментарий, обычно ФИО и другая инфа                                                                                                                       |     |
| **6. home directory** | `/home/alex`     | Путь к домашнему каталогу                                                                                                                                   |     |
| **7. shell**          | `/bin/bash`      | Какой shell запускать при входе                                                                                                                             |     |

- #### UID:
	- `0` — суперпользователь (**root**)
	- `1–99` — системные учётки
	- `100–999` — служебные аккаунты/демоны
	- `1000+` — обычные пользователи (в Debian/Ubuntu, в других дистрибутивах может быть по-другому)


### Shadow file
---
Файл **`/etc/shadow`** хранит **хэшированные пароли пользователей** и параметры их действия (сроки, ограничения и т.д.).

1. **Имя пользователя**  
    Должно совпадать с именем из `/etc/passwd`.
2. **Хэш пароля**
    - `x` в `/etc/passwd` указывает, что пароль хранится здесь.
    - Символы:
        - `*` (отключена) или `!` (пароль заблокирован) → учётка заблокирована.
        - пустое поле → вход без пароля.
        - `$id$salt$hash` → зашифрованный пароль (например, `$6$` = SHA-512).
3. **Последняя смена пароля**  
    Количество дней с 1 января 1970 (Unix epoch).
4. **Мин. срок**  
    Минимум дней перед сменой пароля (0 = можно менять хоть каждый день).
5. **Макс. срок**  
    Через сколько дней пароль **обязателен к смене**.
6. **Предупреждение**  
    За сколько дней до истечения система будет предупреждать.
7. **Блокировка (inactivity)**  
    Сколько дней после истечения пароль ещё работает (0 = сразу блок).
8. **Истечение учётки**  
    Дата (в днях от 1970), после которой учётка полностью отключается.
9. **Зарезервировано** (обычно пустое).

*In most distributions today, user authentication doesn't rely on just the `/etc/shadow` file; there are other mechanisms in place, such as PAM (Pluggable Authentication Modules), that replace authentication.*


### Group file
---
Another file used in user management is the `/etc/group` file. This file allows for different groups with different permissions.

Каждый пользователь в Linux принадлежит хотя бы к **одной основной группе** (обычно совпадает с его именем) и может быть в дополнительных группах.

- **group_name** → имя группы (например `sudo`, `users`, `wheel`)
- **password** → обычно `x` или пусто
    - В старых системах тут мог храниться пароль для входа в группу (сейчас это устарело).
    - Если пароль есть, он хранится в `/etc/gshadow`.
- **GID** → числовой идентификатор группы (Group ID).
    - `0` → группа root
    - `1000+` → обычные пользовательские группы
- **user_list** → список пользователей через запятую, входящих в группу (дополнительное членство).
