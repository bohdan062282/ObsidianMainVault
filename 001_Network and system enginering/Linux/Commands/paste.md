### Description
По факту из двух файлов обьединяет по строкам, то есть , 1я одного + 1я второго и т. д., с разделителем табуляции.

---
### Basic syntax
Файлы просто через пробел тыкать.

- `-s` - обьединить последовательно, то есть просто каждая строка одного через разделитель становится, потом на новой строке для другого файла
- `-d` - разделитель в ' '
