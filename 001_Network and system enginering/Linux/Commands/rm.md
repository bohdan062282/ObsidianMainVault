### Description

Папки, даже если пустые, удаляет только с рекурсией, поэтому для удаления пустых папок можно просто юзануть `rmdir`.

---
### Basic syntax
- `-r` — рекурсивно (для папок).
- `-f` — принудительно (без вопросов).
- `-i` — спрашивать подтверждение.
- `-v` - так же как и для остальных команд для работы с несколькими файлами, отображает с какими файлами была выполнена операция.
