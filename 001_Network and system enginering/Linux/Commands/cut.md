### Description
Позволяет вырезать **определённые поля, символы или байты** из строк файла или потока. Часто используется для обработки CSV, логов, табличных данных.

---
### Basic syntax
- `-f <номер>` — выбрать поле/колонку по номеру (нумерация с 1) (по идее использовать при разделителях, как раз выберед по порядку и для каждой строки)
- `-d <разделитель>` — указать разделитель полей (по умолчанию табуляция).
- `-c <символы>` — выбрать определённые символы из строки.
- `-b <байты>` — выбрать определённые байты (редко используется).

*после ключей значения можно указать через запятую, например, количество полей или номера символов.*
