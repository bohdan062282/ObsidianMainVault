### Description
Терминальный мультиплексор. 

---
### Basic syntax
- #### Сессии

```bash
tmux new -s name        # создать новую сессию
tmux ls                 # список сессий
tmux attach -t name     # подключиться к сессии
tmux kill-session -t name   # убить сессию
```

- #### Управление (по умолчанию префикс = **Ctrl+B**)

```bash
(жмёшь `Ctrl+B`, отпускаешь, потом клавишу)
```

- #### Работа с сессией

```bash
Ctrl+B D    # отсоединиться от сессии
```

- #### Окна

```bash
Ctrl+B C    # создать новое окно
Ctrl+B N    # следующее окно
Ctrl+B P    # предыдущее окно
Ctrl+B <num>  # перейти к окну по номеру
Ctrl+B ,    # переименовать окно`
```

- #### Панели (сплиты)

```bash
Ctrl+B ""   # разделить горизонтально (ну одни кавычки)
Ctrl+B %    # разделить вертикально 
Ctrl+B <стрелка>  # переключиться на соседнюю панель
Ctrl+B X    # закрыть панель
```

#### Полезное

```bash
Ctrl+B ?    # справка по горячим клавишам
Ctrl+B :    # командный режим (ввод команд tmux)`
```
