### Description
Показывает последние строки файла, удобно для логов.

---
### Basic syntax
**Полезные опции:**

- `-n <число>` — количество строк.
- `-f` — следить за изменениями в реальном времени.

---
### Examples
В комбинации с `head` можно посмотреть «срез» файла: например, строки 11–20:
```bash
head -n 20 file.txt | tail -n 10
```
