### Description
list directories

---
### Basic syntax
```bash
ls [опции] [путь]
```

**Полезные опции:**
- `-l` — длинный формат (права, владелец, размер, дата).
- `-a` — показать скрытые файлы (начинаются с `.`).
- `-h` — размеры в читаемом виде (KB, MB).
- `-t` — сортировать по времени.
- `-d` - вроде как шоб посмотреть именно про конкретный каталог а не его содержимое

- `-R` - ну можно рекурсивно для всех папок вывести
- `-r` - рееверс сорт
- `-F` - показывает папки со слешами
