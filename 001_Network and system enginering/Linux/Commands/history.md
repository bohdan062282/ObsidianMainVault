### Basic syntax
- `[количество]` — показать указанное число последних команд (например, `history 20`).
- `-c` — очистить историю текущей сессии.
- `-w` — записать текущую историю в файл (обычно `~/.bash_history`).
- `-r` — считать историю из файла в текущую сессию.
- `!<номер>` — выполнить команду с указанным номером из истории.
- `!<текст>` — выполнить последнюю команду, начинающуюся с `<текст>`.



---
### Examples

- можно использовать `!!` для воспроизведения прошлой команды
- `Ctrl + R` для *reverse search*
- История обычно хранится в файле `~/.bash_history` для Bash. Для других оболочек файл может быть другим (`~/.zsh_history` для Zsh и т.п.).
- Команды сохраняются в файл истории при выходе из сессии.
- Можно настроить, сколько строк истории хранить (переменная `HISTSIZE` и `HISTFILESIZE`).
- Для мгновенного сохранения истории можно использовать `history -w`.
