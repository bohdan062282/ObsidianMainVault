### Description
`mc` (**Midnight Commander**) — консольный файловый менеджер, похожий на старый Norton Commander: два панеля для навигации по файловой системе, возможность копировать, перемещать, редактировать, просматривать файлы и подключаться по FTP/SFTP прямо из терминала.

---
### Basic syntax
| Команда                | Назначение                                                     |
| ---------------------- | -------------------------------------------------------------- |
| **mc**                 | Сам файловый менеджер                                          |
| **mcedit**             | Встроенный текстовый редактор MC                               |
| **mcview**             | Просмотр файлов в режиме только чтения                         |
#### 🎯 Ключевые фишки MC
- **Навигация** стрелками и Tab для переключения панелей
- **F5** — копировать, **F6** — переместить, **F8** — удалить
- **F3** — просмотр, **F4** — редактировать (через `mcedit`)
- Поддержка **FTP/SFTP**:
    `cd ftp://user@server cd sftp://user@server`
- Работа с архивами как с папками (tar, zip, etc.)
- Возможность запускать команды прямо из панелей
