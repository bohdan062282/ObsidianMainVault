### Description
Замена, удаление и преобразование символов.

`tr` работает **только со стандартным вводом и выводом** (stdin/stdout), **не принимает файлы напрямую**, но можно использовать конвейер (`|`) или перенаправление.  
Чаще всего используется для:
- замены символов,
- удаления символов,
- преобразования регистра.

---
### Basic syntax
```bash
tr [опции] SET1 [SET2]
```
- `SET1` — символы, которые нужно найти.
- `SET2` — символы, на которые нужно заменить.
- Если `SET2` нет — часто используют опцию `-d` для удаления.

|Опция|Описание|
|---|---|
|`-d`|Удалить символы из SET1.|
|`-s`|Сжать повторяющиеся символы в один.|
|`-c`|Использовать **все символы, кроме указанных**.|

---
### Examples

```bash
echo "hello world" | tr 'a-z' 'A-Z'
# HELLO WORLD
```

```bash
echo "123abc456" | tr -d '0-9'
# abc
```

```bash
echo "aaabbcccddd" | tr -s 'a-z'
# abcd
```

```bash
echo "a b c" | tr ' ' '\t'
# a   b   c
```

```bash
echo "hello 123" | tr -c 'a-z' '_'
# hello___
```
