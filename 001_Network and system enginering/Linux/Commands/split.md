### Description
`split` разбивает файл на несколько маленьких файлов по размеру или по количеству строк.  
По умолчанию создаёт файлы с именами `xaa`, `xab`, `xac` и т.д.

---
### Basic syntax
```bash
split [опции] файл [префикс]
```

- `-l <число>` — указать количество строк в каждом куске.
- `-b <размер>` — указать размер каждого куска (например, `10K`, `5M`).
- `-d` — использовать цифровые суффиксы вместо буквенных.
---
### Examples
```bash
split -l 50 -d data.txt chunk_
# chunk_00, chunk_01, ...
```
