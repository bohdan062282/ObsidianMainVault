### Description
обьединяет столбцы, разделенные пробелом по дефолту, за каким-то общим столбцом и берёт общий один раз только, остальное по идее обрезает.

---
### Basic syntax
По дефолту берет общим первый столбец и разделение - пробел.

- для того что бы указать в каком файле общий столбец какой в порядке можно сделать `join -1 2 -2 1 file1.txt file2.txt` - где каждый ключ это соответственно порядок файла и к нему номер столбца.
- `-t 'разделитель'`
