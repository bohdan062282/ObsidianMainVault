### Description
удаление или подсчёт повторяющихся строк.

`uniq` работает **только с последовательными одинаковыми строками**.  
Поэтому чаще всего сначала делают `sort`, чтобы одинаковые строки шли подряд.

---
### Basic syntax

| Опция  | Описание                                         |     |
| ------ | ------------------------------------------------ | --- |
| `-c`   | Добавить количество повторов перед строкой.      |     |
| `-d`   | Вывести только повторяющиеся строки.             |     |
| `-u`   | Вывести только уникальные строки (без повторов). |     |
| `-i`   | Игнорировать регистр.                            |     |
| `-f N` | Пропустить первые N полей при сравнении.         |     |
| `-s N` | Пропустить первые N символов при сравнении.      |     |
