### Description
Конкретно показывает все переменные окружения усера.

#### Находится в:
##### **Пользовательские конфиги:**
- `~/.bashrc` — загружается в интерактивных сеансах, часто задаёт переменные окружения.
- `~/.bash_profile` или `~/.profile` — загружаются при логин-шелле, тоже могут содержать `export VAR=value`.
- `~/.pam_environment` — отдельный файл для переменных окружения (используется PAM при входе в систему).
#### **Системные конфиги:**
- `/etc/environment` — **глобальный файл переменных окружения** (самый "env-файл", который обычно имеют в виду).
