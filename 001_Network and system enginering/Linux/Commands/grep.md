### Basic syntax
```bash
grep [опции] PATTERN [файл...]
```

| Опция       | Описание                                                     |
| ----------- | ------------------------------------------------------------ |
| `-i`        | Игнорировать регистр букв.                                   |
| `-v`        | Вывести **строки, которые не соответствуют** шаблону.        |
| `-c`        | Вывести только количество совпадений.                        |
| `-n`        | Показать номер строки вместе с совпадением.                  |
| `-r` / `-R` | Рекурсивный поиск в каталогах.                               |
| `-l`        | Показать только имена файлов с совпадением.                  |
| `-w`        | Соответствие только целому слову.                            |
| `-E`        | Использовать расширенные регулярные выражения (как `egrep`). |
