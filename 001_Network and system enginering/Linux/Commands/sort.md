### Basic syntax

| Опция         | Описание                                               |
| ------------- | ------------------------------------------------------ |
| `-r`          | Обратный порядок (reverse).                            |
| `-n`          | Числовая сортировка.                                   |
| `-k N[,M]`    | Сортировка по полю N (и до поля M).                    |
| `-t 'символ'` | Указать разделитель полей.                             |
| `-u`          | Удалить дубликаты (оставить уникальные строки).        |
| `-f`          | Игнорировать регистр букв.                             |
| `-h`          | "Человеческая" сортировка размеров (`1K`, `2M`, `3G`). |
| `-o файл`     | Записать результат в файл.                             |

- можно отсортировать записи обратно в тот же файл через `-o`
