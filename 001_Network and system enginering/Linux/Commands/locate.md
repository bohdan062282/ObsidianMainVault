### Description
`locate` ищет файлы и каталоги **по имени** в заранее созданной базе данных (`mlocate.db`).  
Она **очень быстрая**, потому что не обходит файловую систему в реальном времени, а ищет в индексированной базе.

---
### Basic syntax
| Опция        | Описание                                                       |
| ------------ | -------------------------------------------------------------- |
| `-i`         | Игнорировать регистр букв при поиске.                          |
| `-r`         | Использовать регулярные выражения.                             |
| `-c`         | Показать только количество совпадений.                         |
| `-n N`       | Ограничить вывод первыми N совпадениями.                       |
| `--existing` | Показать только существующие файлы (не учитываются удалённые). |
| `updatedb`   | Команда для обновления базы данных поиска (требует sudo).      |
- `locate` быстрый, но может показывать устаревшие файлы, если база не обновлялась.
- Если нужен поиск в реальном времени, лучше использовать `find`, но он медленнее.
