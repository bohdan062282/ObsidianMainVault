## Regular expressions
| Символ  | Описание                                 | Пример                                        |
| ------- | ---------------------------------------- | --------------------------------------------- |
| `.`     | Любой одиночный символ                   | `a.b` → совпадает с `aab`, `acb`              |
| `^`     | Начало строки                            | `^Hello` → строки, начинающиеся с `Hello`     |
| `$`     | Конец строки                             | `world$` → строки, заканчивающиеся на `world` |
| `*`     | 0 или более повторов предыдущего символа | `a*` → "", "a", "aa", ...                     |
| `+`     | 1 или более повторов                     | `a+` → "a", "aa", "aaa", ...                  |
| `?`     | 0 или 1 повтор                           | `a?` → "" или "a"                             |
| `[]`    | Любой символ из набора                   | `[abc]` → "a" или "b" или "c"                 |
| `[^]`   | Любой символ, **кроме** указанных        | `[^abc]` → любой, кроме "a", "b", "c"         |
| `{n}`   | Ровно n повторов                         | `a{3}` → "aaa"                                |
| `{n,m}` | От n до m повторов                       | `a{2,4}` → "aa", "aaa", "aaaa"                |
| `       | `                                        | Логическое «или»                              |
| `()`    | Группировка                              | `(ab)+` → "ab", "abab", ...                   |
| `\`     | Экранирование специальных символов       | `\.` → точка, а не любой символ               |
