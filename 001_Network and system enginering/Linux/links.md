## links
### 1. Жёсткая ссылка (hard link)
**Описание:**
- Жёсткая ссылка — это **дополнительное имя для существующего файла**.
- Ссылается **не на имя файла**, а на его **inode** (уникальный идентификатор на диске).
- У файла может быть **несколько жёстких ссылок**, они равноправны.
- Если исходный файл удалить, содержимое остаётся доступным через другие жёсткие ссылки.
**Особенности:**
- Жёсткая ссылка **не может ссылаться на каталог** (обычно) и **не может ссылаться на файл на другом разделе/диске**.
- Удаление одной ссылки **не удаляет файл**, пока есть хотя бы одна ссылка.

```bash
echo "Hello" > file.txt
ln file.txt hardlink.txt
ls -li
```

### 2. Символическая ссылка (soft link, symlink)

**Описание:**
- Символическая ссылка — это **отдельный файл**, который содержит путь к другому файлу или каталогу.
- Можно ссылаться на **каталоги** и файлы на других разделах.
- Если исходный файл удалить, ссылка станет **битой (broken)**.

```
ln -s исходный_файл ссылка
```

---
## Notes
- Используй **жёсткие ссылки**, когда нужно несколько имён для одного файла на одном разделе.
- Используй **символические ссылки**, если нужен быстрый ярлык на каталог или файл на другом диске.
