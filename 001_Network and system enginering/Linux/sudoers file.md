## Description
`sudoers` — конфигурационный файл, который определяет **кто и какие команды может выполнять через `sudo`**, и при каких условиях.
```bash
/etc/sudoers
```

---
## sudoers file
*Для редактирования только `visudo`.*
- `visudo` проверит синтаксис перед сохранением.
- Если ты ошибёшься, `sudo` может перестать работать, и придётся лезть в систему через root-доступ.

## Notes
### Синтаксис записей:
```bash
user    host    = (runas)    commands
```
- **user** — имя пользователя или группа (`%groupname`).
- **host** — с каких хостов можно выполнять (`ALL` — с любых).
- **runas** — от имени какого пользователя можно выполнять (`ALL` — любого, обычно root).
- **commands** — список команд (с полными путями, например `/usr/bin/apt`).

#### Пример 1 — дать пользователю `alex` права на всё
```bash
alex    ALL=(ALL:ALL) ALL
```

#### Пример 2 — дать группе `admins` права на всё
```bash
%admins ALL=(ALL:ALL) ALL
```

#### Пример 3 — дать `alex` права только на перезапуск Apache без пароля
```bash
alex ALL=(ALL) NOPASSWD: /bin/systemctl restart apache2
```

В конце `/etc/sudoers` часто есть строка:
`#includedir /etc/sudoers.d`
- Это значит, что все файлы в `/etc/sudoers.d/` тоже загружаются.
- Удобно добавлять конфиги для отдельных пользователей без правки основного `sudoers`.

После изменений можно проверить:
```bash
sudo -l   # показывает, что именно разрешено текущему пользователю
```
