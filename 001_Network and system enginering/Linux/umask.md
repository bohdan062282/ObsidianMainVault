## Description
**umask (user file creation mode mask)** — это маска (набор бит), которая задаёт **права по умолчанию** для новых файлов и директорий.

Она работает так:
- ОС берёт **максимально возможные права** (для файлов это `666`, для директорий — `777`)
- и **вычитает маску** (умножением по битам).

---
## umask
`umask 022`

Пример:
- Максимальные права для файла: `666` (rw-rw-rw-)
- Установим маску: `umask 022`
- Результат: `644` (rw-r--r--)  
    → т.е. файл доступен на чтение всем, но писать может только владелец.

Для директории:
- Максимум: `777` (rwxrwxrwx)
- С маской `022` → `755` (rwxr-xr-x).

### Где задаётся umask
- В текущей сессии (просто командой `umask 022`).
- В **~/.bashrc** или **~/.profile** — для конкретного пользователя.
- В **/etc/profile** или **/etc/login.defs** — глобально для всех.

---
## Notes
- `022` → файлы `644`, директории `755` (чтение всем, запись только владельцу).
- `002` → файлы `664`, директории `775` (удобно для совместной работы в группе).
- `077` → файлы `600`, директории `700` (полный доступ только владельцу.

*Если хочешь максимально безопасно — ставь `077`, если удобно работать в группе — `002`, если обычная система — `022`.*
