## Description
Основные команды для управления пользователями: **`useradd`**, **`userdel`**, **`passwd`**.

---
## User management tools
### useradd
---
По сути — добавляет строку в `/etc/passwd`, создаёт домашний каталог и задаёт настройки.

- `-m` — создать домашний каталог (`/home/username`)
- `-d /путь` — указать другой домашний каталог
- `-s /bin/bash` — указать оболочку (по умолчанию может быть `/bin/sh` или `/usr/sbin/nologin`)
- `-g group` — указать основную группу (GID)
- `-G group1,group2` — добавить в дополнительные группы
- `-u UID` — указать конкретный UID
- `-c "комментарий"` — добавить описание (например ФИО)

- #### Пример:

	`sudo useradd -m -s /bin/bash -G sudo,developers alex`
	
	Создаст пользователя **alex**:
	- домашняя папка `/home/alex`
	- оболочка `/bin/bash`
	- группы: `sudo` и `developers`


### userdel
---
- `-r` — удалить вместе с домашним каталогом и почтой (`/var/mail/username`).
- Без `-r` → пользователь удаляется, но файлы в системе остаются.

- #### Пример:
	`sudo userdel -r alex`
	Удалит пользователя **alex** и его `/home/alex`.


### passwd
---
- Если запустить без аргументов (`passwd`), меняется пароль **текущего пользователя**.
- Если `passwd username` (с `sudo`), можно сменить пароль другого пользователя.

**Опции**:
- `-l user` → заблокировать учётку (запретить логин)
- `-u user` → разблокировать
- `-d user` → удалить пароль (логин без пароля)
- `-e user` → заставить сменить пароль при следующем входе

```bash
sudo passwd -l alex   # заблокировать пароль (логин по паролю невозможен)
sudo passwd -u alex   # разблокировать пароль`
```

*⚠️ Заблокированный пользователь может всё ещё войти, если у него настроен доступ по SSH-ключу или другой метод.*


### chage
---
**Описание**: управляет политикой паролей пользователя (срок действия, срок действия учётки).  
**Синтаксис**:
`chage [опции] username`

**Основные опции**:
- `-l` → показать инфу о пароле (expiry, min/max days и т.д.)
- `-M DAYS` → максимальное количество дней действия пароля
- `-m DAYS` → минимальное количество дней перед сменой пароля
- `-W DAYS` → за сколько дней предупреждать до истечения
- `-E DATE` → дата истечения учётной записи (в формате YYYY-MM-DD)

**Примеры**:

```bash
chage -l bogdan   # посмотреть срок действия пароля юзера bogdan 
chage -M 90 bogdan      # пароль живёт максимум 90 дней
chage -E 2025-12-31 bogdan  # учётка заблокируется в конце 2025 года
```


### usermod
---
**Описание**: изменяет параметры существующего пользователя.  
**Синтаксис**:
`usermod [опции] username`

**Основные опции**:
- `-aG group user` → добавить юзера в доп. группу (очень часто юзается)
- `-g group user` → сменить основную группу
- `-d /home/newdir user` → сменить домашнюю директорию
- `-l newname oldname` → переименовать юзера
- `-s /bin/zsh user` → сменить shell

**Примеры**:
```bash
usermod -aG sudo bogdan   # добавить bogdan в группу
sudo usermod -s /bin/bash bogdan  # сменить шелл на bash
usermod -d /home/newhome bogdan  # сменить домашку

⚠️ Важно: без `-a` при добавлении в группу — все старые группы сотрутся!
```

## Notes
Команды для простого просмотра:
- `groups username`
- `id username`
- `who` - кто залогинен
- `last`
- `chsh -s путь` - поменять оболочку
