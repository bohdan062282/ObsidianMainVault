## permission bits
### SUID
Set User ID — это специальный бит прав доступа в Linux/Unix, который заставляет программу выполняться **с правами владельца файла**, а не того пользователя, кто её запускает.

Вместо обычного `x` у владельца стоит `s` → это и есть **SUID**.

*По сути надо шоб программа могла юзать файлы, которые не может юзать юзер, хоть он может запустить программу.*
``
```bash
chmod u+s [файл]
sudo chmod 4755 [myfile]
```

### SGID
```bash
sudo chmod g+s myfile
sudo chmod 2555 myfile
```

Так же само, только х будет в бите исполнения группы.

- #### SGID на директории

	Если на директории стоит SGID, то **все новые файлы и поддиректории внутри неё наследуют GID директории**, а не GID пользователя.

### Sticky bit
Применяется **только к директориям** (на файлах в современных системах уже не используется). Ограничивает удаление или изменение фийлов в директории. Может менять только владелец файла, владелец директории или рут.

```bash
ls -ld /tmp
drwxrwxrwt 10 root root 4096 Sep 23 14:31 /tmp
```
- `t` → Sticky Bit установлен
- `T` → Sticky Bit есть, но у группы нет **x** (исполнения)

```bash
sudo chmod +t mydir
sudo chmod 1755 mydir
```
