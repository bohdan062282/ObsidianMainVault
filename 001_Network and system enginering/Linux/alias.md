### Description
Позволяет задать короткое имя для длинной команды или команды с опциями.

---
### Basic syntax
```bash
alias имя='команда'
```

- `имя` — это то, что ты будешь вводить вместо всей команды.
- Если команда содержит пробелы или специальные символы, её **нужно брать в одинарные кавычки**.
- Работает только в текущей сессии, если не сохранить в конфиг (~/.bashrc or ~/.zshrc).
	- прописать в конце или дето алиас
	- `source ~/.bashrc`
- можно ремувнуть с помощью `unalias`.
